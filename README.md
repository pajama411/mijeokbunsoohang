## 핵심 데모 조작법

### 2차 곡선 — 4번째 페이지

1. 그래프 빈 영역을 **3번 클릭**하면 제어점이 미리 설정된 예쁜 위치에 하나씩 나타납니다.
2. **3번째 클릭 직후 전체 곡선이 표시**되며 약 1.25초 동안 빛나는 선이 곡선을 따라 그려집니다.
3. 이때부터 제어점을 드래그해 곡선을 바꿀 수 있습니다.
4. 그래프 빈 곳이나 `다음 단계` 버튼을 누르면 제어 선분 → 중점 A → 중점 B → A-B 연결선 → Q가 차례로 표시됩니다.
5. 마지막 구성 단계를 마치면 `t` 슬라이더와 자동 재생이 활성화됩니다.

### 3차 곡선 — 5번째 페이지

1. 그래프 빈 곳을 **4번 클릭**하면 기본 S자형 곡선과 제어점 네 개가 나타납니다.
2. **4번째 클릭 직후** 약 1.4초 동안 곡선 그리기 애니메이션이 실행됩니다.
3. 제어점 드래그 → 곡선 실시간 갱신을 시연하세요.
4. `다음 단계`로 A/B/C → D/E → Q 보간 과정 확인.
5. 마지막 단계까지 완료하면 `t`와 `3D SPEED`가 활성화됩니다. 빠르게 시연하려면 `완성 보기`를 사용합니다.

### 가중치 — 6번째 페이지

- `t`를 0에서 1로 움직여 가중치 (w_0,w_1,w_2,w_3)의 변화를 확인합니다.
- 4개 가중치는 항상 0 이상이며 합은 1입니다.
- 자동 재생을 누르면 그래프 점들과 하단 색 막대가 움직입니다.

### 미적분 I — 7번째 페이지

- 제어점의 x좌표를 `0, 1/3, 2/3, 1`로 고정했으므로 **x(t)=t**입니다.
- 세로좌표가 3차함수인 `f(t)`이고, 평균변화율 `[f(t+h)-f(t)]/h`는 `h→0`일 때 미분계수 `f′(t)`가 됩니다.
- 파란 할선과 분홍 접선, 도함수 그래프 및 기울기 오차를 비교합니다.

### CSS 실험 — 8~9번째 페이지

- 8페이지에서는 프리셋과 제어점 드래그로 CSS easing의 차이를 비교합니다.
- 9페이지에서는 네 값을 슬라이더로 바꾸고 `움직임 비교`를 누릅니다. 실제 CSS `cubic-bezier()` 값으로 브라우저 요소가 이동합니다.

## 수학과 구현에서 유의할 점

- 2차·3차 베지어 곡선은 한 번 중점을 계산해서 생기는 게 아니라 **매개변수 t를 0~1까지 변화시킬 때 마지막 점 Q(t)의 자취**로 정의됩니다.
- 곡선의 수학적 계산과 사용자가 화면에서 보는 시각화는 Canvas/JavaScript로 구현했고, CSS는 스타일과 실제 `cubic-bezier()` 애니메이션에 사용했습니다.
- x(t)=t가 되도록 따로 제어한 **7페이지의 3차함수**를 미분 I의 기본 개념과 직접 연결했습니다. 일반적인 2차원 베지어 곡선을 그대로 y=f(x)로 가정하지 않았습니다.
