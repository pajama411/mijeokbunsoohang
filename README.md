# 베지어 곡선의 생성 원리와 미적분 I

2022 개정 **미적분 I** 교과탐구 발표용 웹사이트입니다. 3분·7장 구성으로, 실제 발표 중 마우스를 클릭해 곡선을 순서대로 만들 수 있습니다.

## 사이트

https://pajama411.github.io/mijeokbunsoohang/

공개 주소가 열리지 않으면 GitHub에서 Settings → Pages → Deploy from a branch → `main` / `(root)`를 설정해야 합니다.

## 발표 중 클릭하는 순서

### 1. 직선 만들기 — 2번째 장 (18초)
1. 처음에는 빈 그래프입니다. **클릭하는 위치와 관계없이 준비된 예시 위치에 제어점이 나타납니다.**
2. 원하는 위치를 클릭해 **P₀**를 찍습니다.
3. 다른 곳을 클릭해 **P₁**을 찍습니다. 두 점 사이 직선이 나타납니다.
4. `위치 t`를 움직이면 `L(t)=(1−t)P₀+tP₁`에 해당하는 점이 이동합니다.
5. 완성 후 제어점을 드래그해 다시 이동시킬 수 있습니다. `다시 시작`으로 초기화합니다.

### 2. 2차 베지어 곡선 — 3번째 장 (42초)
1. 처음에는 빈 그래프입니다. 클릭 3번으로 **P₀, P₁, P₂**를 놓습니다.
2. 클릭 3번을 마치면 보기 좋은 **아치형 곡선의 기본 제어점 배치**가 완성됩니다. 점을 옮기려면 제어점을 드래그하세요.
3. **다음 단계** 버튼이나 그래프의 빈 곳을 클릭할 때마다 아래 요소를 순서대로 표시합니다.
   - 두 제어 선분
   - P₀–P₁의 **중점 A**
   - P₁–P₂의 **중점 B**
   - A–B 연결선
   - A–B의 **중점 Q**
   - **완성된 2차 베지어 곡선**
4. 마지막 단계가 끝나면 `t` 슬라이더와 재생 버튼이 활성화됩니다.
5. **중점만 찍어서 곡선이 생기는 것은 아닙니다.** 처음에는 `t=0.5`여서 중점을 구한 것이고, `t`를 0부터 1까지 바꾸었을 때 마지막 점 Q(t)가 지나가는 **자취가 곡선**입니다.
6. 완성한 뒤에는 제어점을 드래그하거나 초기화할 수 있습니다.

### 3. 3차 베지어 곡선 — 4번째 장 (36초)
1. 빈 그래프를 네 번 클릭하면 **미리 정한 S자형 곡선의 제어점 P₀~P₃**이 차례대로 나타납니다. 클릭한 정확한 위치에 점이 생기는 것은 아닙니다.
2. 이후 클릭/다음 단계: 제어 선분 → 중점 **A** → **B** → **C** → A·B·C 연결 → 중점 **D** → **E** → D·E 연결 → 중점 **Q** → 3차 곡선.
3. 끝나면 `t`를 조작해 Q(t)가 이동하는 모습을 확인하고, **P₀~P₃를 드래그해서 곡선 모양을 바꿉니다.**
4. 시간이 부족할 경우 `완성 보기`로 전체 과정을 건너뛸 수 있습니다.
5. **3D SPEED**는 곡선이 완성된 뒤 활성화됩니다. 입체 높이는 변화 속도 `|B′(t)|`에 비례하는 보조 시각화입니다.

### 4. 미적분 I — 5번째 장 (50초)
- 제어점 가로좌표 `0, ⅓, ⅔, 1`을 고정하여 `x(t)=t`가 되게 했습니다.
- 세로좌표 `y=f(t)`는 3차다항함수입니다.
- `Δt`를 줄이면 할선의 기울기 `[f(t+Δt)−f(t)]/Δt`가 미분계수 `f′(t)`로 수렴합니다.
- 도함수, 오차 그래프, 평균·순간변화율 차트를 전환할 수 있습니다.

## 조작 팁

- **점 찍기**: 빈 그래프를 클릭하면 예시 위치에 제어점이 하나씩 나타남. 임의의 위치로 옮기려면 점을 드래그
- **다음 단계**: 그래프 빈 곳을 클릭하거나 화면 아래 `다음 단계` 버튼
- **점 이동**: 필요한 점을 모두 찍은 다음 해당 점을 드래그
- **초기화**: 각 그래프의 `다시 시작` 또는 `초기화`
- **발표 이동**: 좌우 화살표, 화면 하단 이동 버튼
- **전체 화면**: `F` / 발표 대본: `N`
- **문구 직접 수정**: 상단 `EDIT` → 문구 편집 → `SAVE HTML`로 수정본 저장
- **페이지 스냅**: 하단 `SNAP`, **언어 변경**: `EN/KO`
