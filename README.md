# CURVE.STUDIO — Bézier × 미적분 I

2022 개정 **미적분 I** 교과 탐구 발표용 인터랙티브 웹사이트입니다. 코딩애플의 선형 보간 설명에서 출발해 2차·3차 베지어 곡선과 **평균변화율·미분계수·도함수·접선**을 시각화합니다.

## HTML 기능 8가지

1. **3D:** 4번째 슬라이드의 `3D SPEED`를 누르면 3차 베지어 곡선을 위치 x·y와 정규화된 높이 `z ∝ |B′(t)|`로 볼 수 있습니다. 마우스 드래그로 회전, 휠로 확대, Z SCALE 슬라이더로 높이를 조절합니다. **실제 2차원 베지어 곡선이 3D에서 계산된다는 뜻이 아닙니다.**
2. **차트 다양화:** 5번째 슬라이드의 f′(t) 도함수 선 그래프, Δt에 따른 오차, 평균·순간변화율 막대 비교 사이에서 전환합니다.
3. **실시간 입력:** 제어점 드래그·슬라이더가 그래프, 기울기, 수식, 애니메이션에 즉시 반영됩니다.
4. **시뮬레이션:** 2차·3차 곡선 생성에 PLAY와 3차의 STEP 1/2/3을 사용할 수 있습니다.
5. **페이지 스냅:** 아래 `⇵ SNAP` 버튼을 누르면 슬라이드별 스크롤 스냅 모드가 켜집니다.
6. **번역:** 아래 `EN/KO` 버튼으로 슬라이드의 주요 문구와 발표자 노트를 전환합니다. 한글 원문을 보존하고, 문구 편집은 KO 모드에서 합니다.
7. **반응형:** 데스크톱·태블릿·모바일에 맞춰 레이아웃이 적응합니다.
8. **배포:** 단일 `index.html` 파일이므로 별도 빌드 없이 GitHub Pages에서 호스팅할 수 있습니다. 상단 `SHARE`로 링크를 복사할 수 있습니다.

## 조작법

- `← / →`: 이전·다음 슬라이드
- `F`: 전체 화면, `N`: 발표 노트
- `EDIT`: 슬라이드 문구 수정, `SAVE HTML`: 수정된 내용을 HTML 파일로 내보내기
- `EXPAND`: 3차 곡선 그래프 전체 확대, `Z`: 그래프 확대 모드 토글
- `2D / 3D SPEED`: 곡선/속도 시각화 전환
- `EN/KO`: 번역, `⇵ SNAP`: 스크롤형 슬라이드 모드
- `SHARE`: 현재 발표 URL 복사

## 교과 범위 정확성

미적분 I 수행평가를 위해 **x(t)=t**가 되도록 5번째 슬라이드의 제어점 가로좌표를 `0, ⅓, ⅔, 1`로 고정했습니다. 따라서 세로좌표는 실제로 **3차다항함수 f(t)**이고, 평균변화율 `[f(t+h)-f(t)]/h`의 극한으로 미분계수 `f′(t)`를 확인합니다. 임의의 2차원 매개변수곡선 전체를 미적분 I 내용으로 오해하지 않도록 구분했습니다.
